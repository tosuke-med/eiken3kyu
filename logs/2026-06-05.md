## Today's Practice Phrases

---

## Correction and Explanation from LLM

3. "multiplies" → **multiplied** (過去分詞形が正しい。"three point two multiplied by ten to the power of 6" または "three point two times ten to the sixth power" とも言える。)

5. "usefult" → **useful** (タイポ)  
   また、文の構造として "Logistic regression is useful **when you have** numerical input variables and categorical output variables." や "Logistic regression is useful **for** numerical input variables and categorical output variables." のほうが自然。
